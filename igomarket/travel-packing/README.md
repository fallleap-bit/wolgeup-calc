# 아이고마켓 · 여행 짐 싸기 장면

- `source/step1-photo.webp`: Gemini ① 전체 실사
- `source/step2-cartoon.webp`: Gemini ② 상품 외 흑백 만화화
- `final.webp` / `final-preview.png`: ②의 배경(완전 흑백 처리) 위에 ①의 상품 7개만 실사로 합성
- `masks/*.png`: 상품별 합성 마스크 (흰색 = 실사 영역)
- `tools/build.py`: 합성 스크립트 (`camping-scene` 폴더 기준이 아니라 이 폴더에서 `python3 tools/build.py` 실행, 결과는 `out/`)

| # | 상품군 | 위치 |
|---|---|---|
| 1 | 캐리어 | 가운데, 열려 있음 (손·소매는 만화로 남김) |
| 2 | 정리 파우치 | 캐리어 왼쪽 바닥 |
| 3 | 투명 세면 파우치 (공병) | 앞쪽 왼쪽 |
| 4 | 메쉬 파우치 | 앞쪽 가운데 |
| 5 | 멀티 어댑터 | 메쉬 파우치 오른쪽 |
| 6 | 3단 우산 | 앞쪽 오른쪽 |
| 7 | 고데기 | 오른쪽 바닥 |

남은 점: 오른쪽 아래 Gemini 표식(반짝이 모양)이 그대로 있음. 침대 위 목베개·안대는 상품에서 제외(만화 유지).
